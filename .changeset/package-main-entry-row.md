`edgefit package` takes the result of a target from the main entry (`.`). The worst subpath is named on a `worst subpath` line, and in the `worst` field of the JSON result, when it is worse. The package table does the same. In the result, `summary` now means the main entry, and the result version is 2. The aggregate of the table has a `worst` field instead of `main` and `decidedBy`. A package without a main entry takes its worst subpath, as before.
