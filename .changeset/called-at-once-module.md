Follow a Node.js module into a function that the code calls at once, as in `(function (stream) { stream.write('x'); })(process.stderr)`. A parameter that is the parent class, through `class extends` or an `extend(Child, parent)` helper of the file that sets `Child.prototype` from `parent.prototype`, as CoffeeScript writes, counts as a class that extends the module.
