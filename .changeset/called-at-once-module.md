Follow a Node.js module into a function that the code calls at once, as in `(function (stream) { stream.write('x'); })(process.stderr)`. A parameter, or a member of it, that a class extends counts as a parent class. So does the second argument of a helper of the file that sets `Child.prototype` from `parent.prototype`, as CoffeeScript writes `extend(Child, parent)`. A `.call`, `.apply` or `.bind` of a parameter is a use of the parameter itself.
