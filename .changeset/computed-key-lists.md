Read a computed key from a list of strings: a `for...of` name, the parameter of a `forEach` callback, an element of an array or of an object, a `.map` that joins a string, and a `const` that the file declares later. A `let` or a `var` holds each value written to it. A `typeof` check and an `if (!obj[key])` fallback guard the same read.
